# 📤 贡献指南 —— 手把手教你上传资料

> 🎉 **不需要会 Git！不需要装任何软件！只需一个 GitHub 账号 + 浏览器，5 分钟搞定。**

---

## 第一步：注册 GitHub 账号

如果已有 GitHub 账号，跳过此步。

1. 打开 [github.com](https://github.com)
2. 点击右上角 **Sign up**，用邮箱注册
3. 验证邮箱后即可使用

---

## 第二步：进入仓库上传页面

点击下方按钮，直达上传界面👇

👉 **[🚀 一键上传资料](https://github.com/Iroul1212/XJTU_EE-study-material/upload/main)**

或者手动进入：
1. 打开 [项目仓库](https://github.com/Iroul1212/XJTU_EE-study-material)
2. 进入目标课程文件夹（如 `电路/`、`高数&CMC/`）
3. 点击右上角 **Add file** → **Upload files**

![上传入口示意](https://docs.github.com/assets/cb-23934/images/help/repository/add-file-dropdown.png)

---

## 第三步：拖拽或选择文件

- 将你的资料文件（PDF、Word、Markdown、图片等）**拖入虚线区域**
- 或点击 **choose your files** 选择文件

支持的文件格式：`.pdf` `.md` `.txt` `.docx` `.pptx` `.jpg` `.png` `.zip` 等

---

## 第四步：填写提交说明

在页面底部填写：

| 字段 | 说明 | 示例 |
|:---|:---|:---|
| **Commit message** | 简要描述你上传了什么 | `添加 2024 电路期末真题` |
| **Extended description** | （可选）补充详细说明 | `包含 A/B 卷及答案解析` |

⚠️ **重要**：选择 **"Create a new branch for this commit and start a pull request"**（默认就是这项），然后点击 **Propose changes**。

---

## 第五步：提交 Pull Request

1. 系统自动跳转到 Pull Request 页面
2. 检查标题和内容无误
3. 点击 **Create pull request** 提交

✅ **完成！** 维护者审核通过后，你的资料就会出现在网站上啦~

---

## 📝 资料整理建议

为了让资料更好地被检索和使用，建议：

| 规则 | 说明 |
|:---|:---|
| 📁 **文件夹** | 按课程分类存放，如 `电路/2024期末/` |
| 📄 **文件名** | 尽量包含课程名+年份+类型，如 `电路_2024秋_期末A卷.pdf` |
| 📖 **README** | 如果上传多份文件，可附带一个 `README.md` 说明内容 |
| 🔗 **Markdown** | 若上传 `.md` 文件，可用链接整理资料索引 |

---

## ❓ 常见问题

**Q: 我没有 GitHub 账号，也不想注册，怎么办？**

A: 可以在 [Issues 页面](https://github.com/Iroul1212/XJTU_EE-study-material/issues) 提 Issue，把资料作为附件上传，维护者会帮你整理入库。

**Q: 上传后多久能看到？**

A: 维护者审核合并后（通常 1-3 天内），你的资料会出现在 [学习资料站](/) 上。

**Q: 可以上传整门课的完整资料包吗？**

A: 当然可以！建议压缩成 `.zip` 上传，并在 commit message 中注明包含的内容。

**Q: 我不确定资料该放哪个文件夹？**

A: 没关系，上传到仓库根目录即可，在 PR 中说明，维护者会帮你归类。
