无论你是哪个专业的同学，都可以通过以下方式快速找到需要的资料：

*   **🔍 搜索直达**：点击左侧搜索框，输入课程名（如 `高数`、`电路`），最快直达目标。

## 📚 资料概览

高数、思修类（思修/史纲/毛概/马原/习思想/军理）、线代、大学物理、工程制图、大物实验、大学化学、大化实验等课程面向所有专业开放。
