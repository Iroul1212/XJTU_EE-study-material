# ⚡欢迎来到 XJTU·EE 学习资料共享站

> 📖 **本站内容完全开源、免费，由西安交通大学电气工程在读学生维护，面向所有电气学院同学。**  
> 💡 *希望通过这份资料，能让你的学习之路少走一些弯路，收获更多启发。*

---

## 🗺️ 快速开始

无论你是想寻找期末复习资料，还是想提前预习下学期的课程，都可以通过以下两种方式快速找到你需要的资料：

*   **🔍 搜索直达**：点击左上角的搜索框，输入课程名（如 `高数`、`电路`），最快直达目标。
*   **📂 分类浏览**：通过左侧导航栏，按课程分类直接定位。

---

## 📚 资料概览

本站目前已经收录了**近30门**电气工程核心课程的资料，涵盖思想政治课、基础通识课、专业基础课及专业实验课。

| 课程分类 | 主要课程 |
| :--- | :--- |
| **思政类** | 思修、史纲、毛概、马原、习思想、军理（国防教育） |
| **数学与基础科学** | 高数&CMC、线代、概率论、复变、数理方程、大学物理、大物实验、大学化学、大化实验 |
| **专业核心课** | 电路、电路实验、模拟电子技术、数电、电磁场、信号与系统、工程制图、大计基 |
| **实验与实践** | 模电数电实验、电磁场和信号与系统实验 |

> *持续更新中，部分课程资料较为紧缺（如模电、信号与系统等），欢迎贡献补充。*

## 🙋‍♀️ 如何贡献？

这个资料库因为大家的无私共享而不断丰富。如果你手头也有整理好的笔记、真题、复习提纲，非常欢迎你参与进来！

你可以通过以下方式帮助这个项目：
*   在 [GitHub 仓库](https://github.com/Iroul1212/XJTU_EE-study-material) 提交 Issue 或 Pull Request。
*   联系维护者上传资料（推荐通过 GitHub 直接提交 PR）。

每多一份资料，可能就有一位同学在复习时多一分把握。
